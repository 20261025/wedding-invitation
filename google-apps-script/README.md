# Google Sheets RSVP 연결

이 폴더의 `Code.gs`는 RSVP 응답을 같은 Google 스프레드시트의 `RSVP` 시트에 저장합니다. 시트와 헤더는 첫 응답 때 자동으로 생성됩니다.

## 한 번만 설정하기

1. RSVP를 모을 새 Google 스프레드시트를 만듭니다.
2. 스프레드시트에서 **확장 프로그램 > Apps Script**를 열고, 기본 코드를 지운 뒤 `Code.gs` 전체를 붙여 넣고 저장합니다.
3. **배포 > 새 배포 > 웹 앱**을 선택합니다.
4. 실행 계정은 **나**, 액세스 권한은 하객이 로그인하지 않아도 쓸 수 있는 가장 넓은 옵션(일반적으로 **모든 사용자**)으로 설정한 뒤 배포합니다.
5. 권한을 승인하고, 표시되는 **웹 앱 URL 중 `/exec`로 끝나는 주소**를 복사합니다. `/dev` 주소는 테스트 전용이라 사용하면 안 됩니다.
6. `src/data/invitation.ts`의 아래 값에 붙여 넣습니다.

```ts
rsvp: {
  googleScriptUrl: 'https://script.google.com/macros/s/여기에_배포_ID/exec',
},
```

배포 후에는 청첩장을 새로 빌드·배포하면 됩니다. 응답은 `RSVP` 시트에서 확인할 수 있습니다.

## 참고

- 하객의 이름·참석 여부 등 개인정보가 시트에 저장됩니다. 시트 공유 권한은 신랑·신부 등 필요한 사람에게만 부여하세요.
- 이 웹 앱 주소는 청첩장에 공개됩니다. 스팸 방지를 위해 수상한 응답은 시트에서 삭제하거나, 필요하면 Apps Script에서 추가 인증을 구현하세요.
